# Telco Customer Churn Analysis

An end-to-end data analytics project focused on understanding customer churn, identifying retention risks, and analyzing revenue impact using Python and data analytics.

## Project Overview
Customer churn is a major challenge for subscription-based businesses. This project analyzes customer, subscription, billing, and support data to identify churn patterns and develop data-driven customer retention strategies.

## Tools & Technologies
- **Python:** Data cleaning and exploratory data analysis
- **Pandas & NumPy:** Data manipulation and feature engineering
- **Matplotlib & Seaborn:** Data visualization
- **SQL:** Data extraction and analytical queries, where applicable
- **Jupyter Notebook:** Analysis and documentation

## Key Performance Indicators
- Churn Rate and Retention Rate
- Churn by Subscription Plan and Contract Type
- Average Revenue Per User (ARPU)
- Customer Tenure and Lifetime Value
- Revenue at Risk
- Relationship between Support Escalations and Churn

## Key Findings
Based on the accompanying project report:

- Overall churn rate: **28.6%**
- Retention rate: **71.4%**
- Monthly contract churn: **55.6%**
- Annual contract churn: **8.3%**
- Karnataka was identified as the most affected state.
- September 2024 recorded the highest reported churn activity.

These findings highlight potential opportunities to improve retention and protect recurring revenue.

## Business Recommendations
1. Prioritize high-risk customers for proactive retention campaigns.
2. Investigate the high churn rate among monthly-contract customers.
3. Analyze regional churn patterns and potential service issues.
4. Improve customer support by investigating recurring complaints and escalations.
5. Monitor retention KPIs and revenue at risk regularly.
